# 🎨 Graphic Designer Portfolio

A modern and responsive **Graphic Designer & Social Media Marketing Portfolio Website** built using HTML, CSS, and JavaScript.

This portfolio showcases creative design projects, social media creatives, branding work, digital marketing campaigns, and real estate marketing creatives.

## 🌐 Live Demo

🔗 **Portfolio:**  
https://github.com/Eshita123456/Portfolio-for-Graphic-Designer

## 📌 About The Project

This website is designed to showcase my work and professional skills in:

- 🎨 Graphic Design
- 📱 Social Media Design
- 🏢 Real Estate Marketing Creatives
- ✨ Brand Identity
- 📢 Digital Marketing
- 🖼️ Creative Campaign Design

The website provides a clean, modern, and responsive interface where visitors can explore different projects and get in touch for collaborations or projects.

---

## ✨ Features

- 📱 Fully responsive design
- 🎨 Modern portfolio UI
- 🗂️ Project category filtering
- 🖼️ Project image gallery
- 🔍 Image/project preview modal
- 📱 Mobile navigation menu
- ✨ Scroll reveal animations
- ⏳ Page loading animation
- 📩 Contact form
- 📧 EmailJS integration
- 🔗 Social media links
- ⚡ Fast and lightweight frontend
- 💻 Cross-browser compatible
